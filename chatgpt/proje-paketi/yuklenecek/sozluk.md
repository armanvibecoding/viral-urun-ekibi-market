# Sözlük (tek terim = tek kavram)

Tüm beceriler ve ajanlar bu anlamları kullanır. Yeni terim gerekirse buraya eklenir, başka dosyada yeniden tanımlanmaz.

| Terim | Anlamı |
|---|---|
| **Aday** | DNA kapılarından geçmiş, AliExpress ürün sayfası açılmış, henüz karar verilmemiş ürün. Arama sonucundaki her kart aday değildir. |
| **Kanıt** | Kaynağı açılabilen bir gözlem: URL + o sayfada okunan değer + okuma tarihi. "Bence", "muhtemelen" kanıt değildir. |
| **Kanıt dosyası** | Kısa listedeki bir aday için yazılan çürütme dosyası (`is/firsat/kanit/NN-urun.md`). SAT kararı bu dosya olmadan verilmez. |
| **Doğrulanamadı** | Geçerli bir sonuç. Veri okunamadıysa (CAPTCHA, giriş duvarı, sayfa yok) böyle yazılır; tahminle doldurulmaz. |
| **DNA** | Viral olmuş ürünlerin ortak özellikleri: `ortak/viral-dna.md`. Kapılar (K1–K3) + 7 ölçüt (V1–V7). |
| **DNA puanı** | V1–V7'den kaç tanesinin tuttuğu (0–7). Eşik ≥4. Kapıdır, sıralama değildir. |
| **Sıra puanı** | Kapıdan geçen adayları sıralamak için 0–11 puan: mekanizma gücü + doygunluk + marj + üretilebilirlik. |
| **Mekanizma** | İzleyicinin neden durduğu/paylaştığı (M1–M14, `viral-dna.md` §3). Arama terimi ürün adından değil mekanizmadan üretilir. |
| **Akraba ürün** | Aynı mekanizmayla milyon izlenme almış, kanıtlı ürün (not numarasıyla). Akrabası olmayan aday zayıftır. |
| **Benzer ≠ aynı** | Aynı ürün = aynı form, aynı mekanizma, aynı ana parça (fotoğrafla karşılaştırılmış). Benzer ürünün satışı, yorumu ya da viral videosu adaya yazılmaz. |
| **Ürün satışı** | AliExpress **ürün sayfasının başlık satırındaki** "N sold". Arama kartındaki sayı, mağaza toplamı ("5,000+") ve "100K+ benzer" ürün satışı değildir. |
| **Normal fiyat** | Ürün sayfasındaki indirimsiz/teklifsiz fiyat. "Yeni müşteri" ($1.09 gibi), "erken kuş", "only 1 left" fiyatı marj hesabında kullanılmaz. |
| **Tutmamış** | Seçilen pazarda henüz büyütülmemiş: AliExpress ürün satışı ≤1.000 **ve** pazar mağazasında (TR: Trendyol; ABD: Amazon + TikTok Shop) aynı ürün yok ya da ≤100 değerlendirmeli **ve** bu ürünün ≥500 bin izlenmeli videosu bulunamadı **ve** pazarda aktif Meta reklamı ≤3. Ölçülemeyen koşul "doğrulanamadı" yazılır, tutmuş/tutmamış sayılmaz. |
| **Tutabilir** | K1–K3 kapılarını geçer, DNA puanı ≥4 ve en az bir kanıtlı akraba ürünü var. |
| **Zaten viral** | Aynı ürünün seçilen pazarda ≥500 bin izlenmeli videosu ya da pazar mağazasında çok satıcılı/çok yorumlu satışı var. Aday ELE olur (sebep: zaten viral). |
| **Doygunluk** | Pazar mağazasında aynı ürünün satıcı sayısı ve fiyat baskısı. Aynı ürün çok satıcıda ve ucuzsa marj ölür. |
| **SAT** | Kanıt dosyası var, çürütme denemeleri tutmadı, mekanizma gerçek alıcı fotoğrafı/videosuyla doğrulandı, sıra puanı ≥8. Ürün `is/NN-urun-adi/` klasörüne geçer. |
| **İZLE** | Güçlü ama bir koşul eksik (doğrulanamayan veri, numune şartı, sezon uzak, sıra puanı 6–7). Ne beklendiği yazılır. |
| **ELE** | Kapıdan kalan, veto edilen, zaten viral olan ya da sıra puanı ≤5 olan aday. Sebep tek cümle, ürüne özgü yazılır; bir daha önerilmez. |
| **Veto** | Kesin eleme sebebi: lisans/marka görünümü, bebek güvenliği iddiası, riskli kargo (sıvı, cam, ateş, pil ağırlıklı, ağır/hacimli). Sağlık ve sonuç dili veto değildir (bkz. Bilgi notu). |
| **Bilgi notu** | Sağlık ya da sonuç dili geçen çıktının sonuna eklenen tek satır: "Bilgi notu (kullanıcının sorumluluğu): …". Metin elenmez, yumuşatılmaz; mevzuat ve platform reklam kuralı kullanıcının işidir (`kurallar.md` IDD-01). Uydurma veri (sahte yorum, sayı, indirim, stok) bundan ayrıdır ve yasaktır (IDD-02). |
| **Sınama** | Ajan çıktısından rastgele 3 sayının kaynağından açılıp kontrol edilmesi. Biri tutmazsa çıktının tamamı "şüpheli" olur. |
| **DROP-MARKA** | Tek ürün etrafında marka kimliği kurmuş dropship mağazası (jenerik tedarik, yeni/küçük hesap, logo/isim/paket). Örnek alınan hedef tip. |
| **GERÇEK-MARKA** | Kendi üretimi/ölçeklenmiş marka. Kreatif fikir için referans, "bizim durumumuz" değildir. |
| **DENEYİCİ** | Sürekli ürün değiştiren, marka hissi vermeyen hesap. Örnek alınmaz. Puanlama: `ortak/marka-skoru.md`. |
| **Kanca** | Videonun ilk 3 saniyesi (görüntü + yazı). |
| **Pazar** | Ürünün satılacağı ülke/bölge (TR, ABD, diğer). `.ekip/KARARLAR.md`'de "pazar" satırıyla tutulur. |
| **Köprü dosyası** | Kollar arasında veri taşıyan üç JSON: `urun-paketi.json` (ürün → mağaza), `magaza-paketi.json` (mağaza → video), `video-paketi.json` (video → mağaza). Yeri `is/NN-urun/magaza/`; şema ve doğrulayıcı `ortak/sozlesme/`, betik `ortak/paket.py`. |
| **Onaylı iddia** | `magaza-paketi.json` `onayli_metinler.iddialar` listesindeki, kaynağı yazılı cümle. Video ve altyazı yalnız bunları söyler; listede olmayan sayı ya da sonuç cümlesi kapıdan geçmez. |
| **Tema modu** | Tam mod = kullanıcıda kayıtlı tema paketi var, şablonlar yazılır. Temasız mod = paket yok; ürün, metin, görsel mağazanın mevcut temasına yazılır, tema istenmez. |
| **Pazar kodu** | Köprü dosyalarında ISO 3166 (`US`, `TR`, `GB`, `DE`…); kullanıcıya Türkçe ad. Teklif tablosundaki `UK` = `GB`. |
| **Niş eki** | Mağazanın niş şablonu (`nis-pet`, `nis-gadget`…). Reklam avının niş kodu `ortak/nis-esleme.tsv` ile çevrilir (`paket.py urun-yaz --nis-kodu`). |
| **Kod adı** | Beceri ve ajanın tek kelimelik İngilizce adı (Radar, Atlas …); kullanıcıya `Kod adı (Türkçe rol)` diye anılır. Tek kaynak `ortak/ad-haritasi.tsv`. |
| **Alias** | Eski beceri adının yönlendirme klasörü (yalnız `SKILL.md`, `<!-- alias: yeni -->` işaretli); 0.4.0'da çalışır, 0.5.0'da silinir. |
| **DEVAM KARTI** | Mağaza aşamalarının hafızası: onaylı ad, renk, yazı, fiyat, metin ve dosya adları. Proje klasöründe `is/NN-urun/magaza/devam-karti.md`; sohbette yapıştırılır. Karttaki onaylı değer değişmez. |
