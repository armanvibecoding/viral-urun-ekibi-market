# Tarifler — betiksiz ChatGPT sürümü

ChatGPT eklenti betiklerini (Python/ffmpeg/HyperFrames) çalıştıramaz. Bu klasördeki tarifler aynı kalite çıtasını **adım adım talimat + ölçülebilir çıta + "kendi çıktını 10 maddeyle denetle" listesi** olarak verir; betiğin yaptığı denetimi sen maddeler üzerinden yaparsın. Hazır istemler: `uretim-istemleri.md`. Kanca/sahne/pazar özeti (kanıt numaralı): `ozet-kanca-sahne-pazar.md`.

| Tarif | Ne zaman |
|---|---|
| 01 ürün videosu (döngü) | tek ürün Reels reklamı — VARSAYILAN |
| 02 hikâye videosu (25 sn) | organik hikâye |
| 03 müşteri senaryosu A+B | müşteri kendi senaryosunu verdi |
| 04 seslendirme | VO gerekli |
| 05 Flow klibi | klip istemi/kredi defteri |
| 06 Trendyol + AliExpress avı | TR ürün bulma |
| 07 Excel teslim | liste dosyası |
| 08 geri bildirim | geri bildirim geldi |
| 09 limit ve devam | limit/kesinti |
| 10 kanca varyasyon testi | aynı çekimden 10+ kanca (+ tekrar yayın deneyi) |
| 11 biçim kopyala | tutmuş biçimin kare sırası + kendi çekimin; biçim kütüphanesi |

**Video tarifleri (01, 02, 03, 10, 11) ilk adımda ön-üretim kartı ister** (pazar → kanca ailesi + kanıt → sahne şablonu → müzik kararı → ilk 1 sn). Kart yazılmadan sonraki adıma geçilmez.

**Her sürümden önce** `sinav-kontrol-listesi.md` elle işaretlenir (üç sabit vaka × yedi özellik; betikli eşleniği `scripts/sinav_kos.py`).
