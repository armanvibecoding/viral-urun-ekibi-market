## Okuma kuralları
- Kod numaraları kanıt izidir: `S063` ürün = `kreatif-notlar.md` içinde **063** notu.
- "(ön-eleme)" etiketli hesap türü otomatik tahmindir; kesin değildir.
- Sayılar gözlem anındaki Instagram/AliExpress değerleridir; bugünkü değer değişmiş olabilir — karar öncesi yeniden açılır.
- Bu dosyalarda kullanıcı verisi yoktur; kullanıcının kendi işleri proje klasöründeki `.ekip/` ve `is/` altına yazılır.
